# Web 管理台

浏览器打开 `http://127.0.0.1:8787/admin`（访问根路径 `/` 会自动跳转）。单文件页面，
不依赖 CDN，离线可用。

## 能做的事

| 区域 | 功能 |
|---|---|
| 概览 | 密钥总数 / 启用中 / 今日请求 / 累计请求，今日新增与服务状态 |
| 趋势 | 近 14 天调用次数柱状图（悬停看当天 tokens） |
| 密钥表 | 生成、复制、改名、备注、设置有效期（天，0=永久）、单把停用/删除 |
| 批量 | 勾选多把 → 批量启用 / 批量停用 / 重置统计 / 批量删除 |
| 鉴权 | `自动`（密钥表非空即校验）/ `强制校验` / `关闭校验`，即时生效 |
| 流水 | 最近 200 条调用（密钥、协议、状态码、耗时） |
| 接入信息 | 网关状态、内核提示词来源与校验结果 |
| 稳定性设置 | 6 个抗卡死参数的可视化开关/输入，改完即时生效、重启保留；可一键恢复默认 |
| 运行日志 | 最近代理日志（内存环形缓冲），每 10 秒自动刷新，可选 100/200/500 条、滚动到底跟随、手动刷新；完整落盘见 `runtime/proxy.log` |
| 积分福利社 | TeleAgent 官方账号的积分余额与签到状态（累计天数/积分、今日是否可领）；「领取今日积分」按钮手动签到领 100 分 |

### 稳定性设置

管理台下半部分的「稳定性设置」区控制长对话存档、会话回收、静默自动续接等行为
（背景见 [RELIABILITY.md](RELIABILITY.md)）。每项标了环境变量名与默认值，`已自定义` 标签表示
当前值来自管理台文件而非环境变量。点「保存」后：

- 立即同步到运行进程（下一轮请求就按新值走），**无需重启**；
- 写入 `runtime/config/runtime.json`，**重启后保留**；
- 管理台的值优先于 `start.cmd` 里的 `set`；点「恢复默认」删除覆盖、回到环境变量/默认值。

接口：`GET /admin/api/state` 的 `runtime` 字段返回各项；
`POST /admin/api/runtime` 传 `{ <项名>: <值> }` 保存，或 `{ reset: true, names: [...] }` 恢复默认。
配置文件路径可用 `TA_RUNTIME_CONFIG_FILE` 改。

### 积分福利社

管理台的「积分福利社」区显示**当前 TeleAgent 登录账号**的积分余额和签到状态：今日是否可领、
累计签到天数、累计领取积分，以及**积分有效期**（汇总到期日 + 每笔明细各自的到期日，
每笔积分自领取起约 30 天有效；明细按到期日升序，7 天内将过期的标红），
每笔下方带**剩余积分占总积分比例的进度条**（如邀请礼 1382.73/3000 显示 46%），快过期的进度条变红）。
点「领取今日积分」会确认后向官方发起签到（每天一次，领 100 分），
已领当天按钮自动置灰；这是唯一有副作用的按钮，其余查询都是只读。

- 数据来自官方客户端前端走的同一批接口（`/user/portal/points/detail` 等），
  鉴权用本地已解密的登录态（token/deviceId/版本），**不用另外登录**，也不碰模型额度。
- 接口：`GET /admin/api/points`（查询）、`POST /admin/api/points/sign`（领取，幂等）。
- **自动签到**：积分卡片里的「自动签到」下拉框三档可选，**即时生效、重启保留**
  （写在积分面板，不在稳定性设置里重复）：
  - `启动检查一次（默认）`：每次代理启动时检查一次，今天没领就顺手领掉（幂等）；
  - `关闭`：不检查、不领取（对应 `TA_AUTO_SIGN=0`）；
  - `启动检查 + 每天0点定时`：启动检查之外，每天 00:00:30 定点执行一次
  （适合长期后台常开、跨天自动领；定点比相对间隔更可预测，也错开整点）。
  官方 app 也内置了每天 08:13 自动领取的预设技能。三档对应环境变量
  `TA_AUTO_SIGN` 的 `2/0/1`（默认/关/每天定时），管理台设置优先于环境变量。
- **最近积分消耗**：卡片下方的表格显示官方**按次**用量记录（时间/模型/实际积分/原价/折扣），
  与实际扣费一致（比管理后台每日汇总精确）。数据来自 `/user/portal/usage/stats/record`，
  只读，可能有数秒写入延迟。官方接口固定每页 10 条（`page_size` 无效），管理台用
  「上一页/下一页」翻页查看全部记录。`GET /admin/api/points/usage?page=N`。
- **回复末尾显示积分（尾注，默认关）**：开启后在模型回复末尾追加"（本次消耗 X 积分）"。
  实现是请求结束后轮询官方用量记录，最多等 `TA_FOOTNOTE_WAIT_MS`（默认 3000ms，在稳定性设置里调）。
  **注意**：官方记录写入常延迟 3–5 秒，3 秒内可能查不到而**不显示尾注**；尾注也会让回复变慢，
  且工具调用轮不加。默认关闭，按需开启。
- 合规提示：这是以你自己的账号领官方每日福利，供本机自用；公开分发请自行评估 ToS 风险。

## 密钥存储与安全

- 密钥保存在 `runtime/config/api-keys.json`（`runtime/` 已被 gitignore），可以直接备份/迁移
- 生成时明文只在这一屏集中展示，之后在列表里也能复制
- 管理台默认只接受**回环地址**访问；服务本身 PC 版也只绑 `127.0.0.1`。
  设 `TA_ADMIN_ALLOW_REMOTE=1` **且**已设 `TA_ADMIN_TOKEN` 时放行局域网访问
  （Docker compose 默认这样配）；只放行不设令牌是危险组合，会自动退回仅回环并打警告
- 想让管理接口也要令牌，启动前设 `TA_ADMIN_TOKEN=xxx`，页面会提示输入
  （存在浏览器 localStorage，只影响管理接口，不影响 `/v1` 调用）
- Docker 端 compose 固定 `TA_REQUIRE_AUTH=1`：端点强制鉴权，未带有效 API 密钥的调用一律 401
- 「会话 / 登录」面板：凭据状态、浏览器登录回执 URL 导入（自动备份 + generation 归 1 +
  可选立即续期验证）、手动续期——NAS 上无需再 `docker exec`
- 环境变量 `TA_API_KEY` 依然可以作为一把「主密钥」长期使用，与管理台密钥并存
